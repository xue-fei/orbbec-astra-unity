## Orbbec Astra Unity：RGB+深度 → 真 Mesh 点云方案
- 通读 `Assets/OrbbecAstra/Scripts` 下 10 个 .cs + 2 个 .compute，确认 RGB+深度实时转点云可行。
- 现状数据链路：DepthFrame(short[], 毫米)→DepthToTexture.compute→`_depthMap`；ColorFrame(byte[],RGB)→ColourToTexture.compute→`_colorMap`。`AstraController.HasDepthRegistration=true`（深度已对齐彩色，逐像素对应）。`AstraUtil` 用 ×0.01 把 mm 转米。DepthToTexture 已持有 float[] 的 ComputeBuffer（`_depthBuffer`）可复用。
- 渲染管线确认：**Built-in 内置管线**（`GraphicsSettings.m_CustomRenderPipeline=0`），manifest 无 URP/HDRP/VFX Graph 包。
- 关键结论：VFX Graph 在当前工程**不可用**（未装包），且本质是视觉特效系统、点不进入真实几何 → 用户决策改用 **Unity 真 Mesh 点云**。
- 推荐方案（Mesh 路线，未实施）：
  - 新增 `DepthToPoints.compute`：读 `_depthBuffer`(float[]) + `_colorMap` + 内参 uniform，算 XYZ(×0.01, 翻转Y)、取 RGB，写 `pointsBuffer`(ComputeBuffer: float3 pos + float3 col)；无效点(depth==0 或 >10000mm)剔除。
  - 新增 `PointCloudMeshRenderer.cs`：建 quad Mesh + argsBuffer；每帧订阅 OnDepthFrameEvent 触发 compute，用 `Graphics.DrawMeshInstancedIndirect` 画 307200 实例（quad 模板 + instanced pointsBuffer）；Shader 用 SV_InstanceID 索引点位置/颜色，点大小可控。仍是真 Mesh 几何，参与深度/遮挡、可读取/导出。
  - 新增 `Shaders/PointCloud.shader`(ShaderLab/Built-in) + `Materials/PointCloud.mat`。
  - 备选：直接用 `Mesh` 顶点缓冲(`Mesh.GetVertexBuffer`)存 307200 点 + `MeshTopology.Points` + MeshRenderer（最纯 Mesh，但 DX11 点大小难控）。
  - 内参硬编码先跑通：fx=fy≈570.34, cx=320, cy=240（备选 ROS 标定 fx=517.30/fy=519.29/cx=326.79/cy=244.56）。
  - 满分辨率 307200 点（640×480）。
- 注意：Y 翻转 + 尺度；关闭/放大 bounds 防视锥剔除；无效点剔除防平面噪声。
- 状态：仅方案，未动工程代码。

## 实施：已写入工程（Agent 模式）
- 新文件 `Scripts/PointCloud/DepthToPoints.compute`：复用 `DepthToTexture._depthBuffer`(float[],mm) 与 `ColourToTexture._colorMapBuffer`(RGB float[],BGR 已处理)，沿用原 compute 的 `maxSize-i` 翻转保证深度/颜色像素对齐；逐像素算 XYZ(×0.01, Y 翻转, 内参 fx/fy/cx/cy 可 Inspector 调)，写 PointsPos/PointsCol(RWStructuredBuffer<float3>)；无效点(depth<=0 或 >cutOff)置 (1e9,1e9,1e9) 由裁剪剔除。
- 新文件 `Scripts/PointCloud/PointCloudMeshRenderer.cs`：Awake/Start 建 quad Mesh + argsBuffer(GraphicsBuffer.IndirectArguments,[6, 307200,0,0,0]) + 自动定位 DepthToTexture/ColourToTexture(可 Inspector 覆盖)；LateUpdate 触发出 compute 后 `Graphics.DrawMeshInstancedIndirect` 画 307200 个实例；点大小经 clip.w 做 billboard 恒像素大小，参与深度遮挡；支持无色时白色兜底。
- 新文件 `Shaders/PointCloud.shader`：Built-in ShaderLab，vertex 用 SV_InstanceID 索引 _PointsPos/_PointsCol，billboard 偏移，fragment 输出颜色；`#pragma target 5.0`。
- 改动 `DepthToTexture.cs`/`ColourToTexture.cs`：各加 `public ComputeBuffer DepthBuffer/ColorBuffer => _...` getter 供复用（原 `_depthBuffer`/`_colorMapBuffer` 私有）。
- 关键设计：LateUpdate 派发，确保 AstraController.Update 内已填充好深度/颜色 buffer；内参与点云朝向(flipY/mirrorX/pointSize)全在 Inspector 可调，便于实机联调。
